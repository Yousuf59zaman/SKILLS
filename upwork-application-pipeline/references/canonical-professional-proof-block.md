# Canonical Professional Proof Block

Use this block in every future Upwork cover letter after the job-specific opening and before the job-specific approach, milestone, budget, timeline, and closing question.

Copy it verbatim by default. Preserve the paragraph order, project order, project names, six URLs, concise descriptions, and final production/showcase distinction. Use plain URLs in the Upwork textarea rather than Markdown link wrappers.

Only change or omit part of the block when:

- Yousuf explicitly requests a change;
- a stated career or project fact is no longer accurate;
- a required URL fails the current public-access check or becomes unsafe;
- Upwork's live form limit requires a shorter version.

When an exception applies, preserve the same meaning and record the reason in the application's durable ready copy. Job-specific copy belongs before and after this block, not inside it.
